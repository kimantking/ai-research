# apps/web — Next.js 프론트엔드 (아직 비어 있습니다)

## 지금 상태: 빈 폴더입니다. 그리고 그게 의도된 것입니다.

**픽셀 사무실은 이 폴더 없이도 완전히 동작합니다.**

현재 화면은 백엔드가 직접 서빙합니다:

```
services/api/static/office.html    ← 단일 파일, 의존성 0
```

`start.ps1` 을 실행하면 `http://localhost:8010` 에서 바로 열립니다.
Node.js 를 설치하지 않으셔도 됩니다.

---

## 왜 Next.js 앱을 지금 만들지 않았나

정직하게 말씀드립니다.

이 프로젝트를 개발한 환경(Anthropic 클라우드 컨테이너)에서
**npm 레지스트리 접근이 정책상 차단**되어 있었습니다. `npm install` 이 403 을 반환합니다.

즉 Next.js 앱을 작성할 수는 있었지만 **한 줄도 실행해볼 수 없었습니다.**

검증하지 못한 코드를 "완성했습니다"라고 드리는 것보다,
**실제로 돌려보고 스크린샷까지 확인한 화면**을 드리는 쪽을 택했습니다.

관련 결정: `docs/DECISIONS.md` D-017, D-018

---

## 그래서 손해 본 것이 있나

기능상으로는 없습니다. 현재 화면에 전부 들어 있습니다.

| 기능 | 상태 |
|---|---|
| 픽셀 사무실 (Canvas 2D, 21개 공간) | ✅ |
| WebSocket 실시간 연동 | ✅ |
| 캐릭터 클릭 → Right Drawer | ✅ |
| 10개 메뉴 전부 | ✅ |
| 다크 리서치 터미널 테마 | ✅ |

없는 것: 컴포넌트 단위 재사용, 타입 안정성, HMR, 코드 스플리팅.
**1인 개발 + 단일 화면 규모에서는 아직 필요하지 않습니다.**

## 언제 Next.js 로 옮기나

다음 중 하나라도 해당되면 그때 옮깁니다.

- 화면이 20개를 넘어가서 단일 HTML 파일 관리가 어려워질 때
- 여러 사람이 프론트엔드를 동시에 작업할 때
- 컴포넌트를 재사용해야 할 때
- SSR/SEO 가 필요해질 때 (현재는 로컬 전용이라 무의미)

## 지금 만들고 싶으시면

antking님 PC 에서는 npm 이 정상 동작하므로 바로 가능합니다.

```powershell
cd C:\ai-research\apps\web
npx create-next-app@latest . --typescript --app --no-tailwind --eslint
```

그다음 `services/api/static/office.html` 의 로직을 컴포넌트로 옮기면 됩니다.
백엔드 API 는 이미 전부 준비되어 있습니다 (`docs/PIXEL_OFFICE.md` 참고).

`setup.ps1` 과 `start.ps1` 은 이 폴더에 `package.json` 이 생기면
**자동으로 감지해서 Next.js 를 함께 띄웁니다.** 스크립트를 고칠 필요가 없습니다.

포트는 `.env` 의 `WEB_PORT` (기본 3010) 를 씁니다.
