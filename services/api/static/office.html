지금 켜져 있는 안전장치

          
    
            
  • Point-in-Time 차단 — 학습·분석 시 T 시점 이후 데이터는 함수에 전달되지 않습니다.
    • 
            
  • Evidence Gate — 근거 ID 없는 숫자가 하나라도 있으면 리포트 발행이 차단됩니다.
    • 
            
  • Bull/Bear 격리 — 토론 단계 전까지 서로의 결과가 컨텍스트에 들어가지 않습니다.
    • 
            
  • 반대근거 강제 — 강세 논거가 나오면 약세 검색어가 자동 생성됩니다.
    • 
            
  • Router 상한 — 한 작업에서 8명을 넘겨 깨울 수 없습니다 (비용 폭발 방지).
    • 
            
  • 근사 중복 탐지 — 복사 기사 50건은 독립 근거 1건으로 셉니다.
    • 
            
  • 시크릿 마스킹 — API 키가 로그에 들어가도 *** 로만 남습니다.
    • 
            
  • 거래일 캘린더 — 백테스트의 T+1 이 정말 다음 거래일인지 검사하고, 아니면 신뢰할 수 없다고 표시합니다.
    • 
            
  • 다중검정 보정 — 후보를 수백 개 검정할 때 우연히 유의해 보이는 것을 BH-FDR 로 걸러냅니다.
    • 
            
  • Walk-forward — 한 번의 분할 운으로 STRONG 이 되지 않도록 창을 밀며 재검증합니다.
    • 
            
  • 공시 날짜 분리 — SEC 데이터는 filing_date(공개일)로만 조회됩니다. period_of_report 로 조회하면 한 달의 미래를 보게 됩니다.
