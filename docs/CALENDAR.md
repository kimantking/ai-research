# 거래일 캘린더 (Phase 11)

---

## 1. 왜 필요한가

백테스트 규칙은 **"T 종가에 신호, T+1 시가에 체결"** 입니다.
그런데 `T+1` 이 **다음 날**이면 틀립니다. **다음 거래일** 이어야 합니다.

```
금요일 종가 신호      →  월요일 시가 체결      (토·일은 장이 없음)
12/24 종가 신호       →  12/26 시가 체결       (12/25 성탄절 휴장)
```

이걸 무시하면 "3일 뒤 수익률" 같은 값이 조용히 어긋나고,
그 오차는 **항상 같은 방향으로** 쌓입니다.

---

## 2. 왜 직접 만들었나

표준은 `exchange_calendars` 패키지지만 외부 의존성입니다.
이 프로젝트는 **"외부 패키지 없이도 전부 돈다"** 를 지키고 있으므로,
필요한 만큼만 규칙으로 구현했습니다.

---

## 3. 지원 거래소

| 코드 | 별칭 | 범위 | 방식 |
|---|---|---|---|
| `XNYS` | NYSE, NASDAQ, XNAS, US | 1970~2035 | 연방 공휴일 규칙 + 관측 규칙 + 특별 휴장 표 |
| `XKRX` | KRX, KOSPI, KOSDAQ, KR | **2015~2035** | 양력 규칙 + 음력 표 + 임시공휴일 표 |

---

## 4. ★ 모르면 모른다고 합니다

한국 증시의 설날·추석·석가탄신일은 **음력**입니다. 계산이 불가능합니다.
2015~2035 표를 넣어 두었고, **표 범위를 벗어나면 예외를 던집니다.**

```python
cal = get_calendar("KRX")
cal.is_session(date(2040, 3, 2))
# CalendarError: XKRX 캘린더는 2015~2035 만 압니다. 추측하지 않습니다.
```

추측해서 답하면 조용히 틀립니다. 그게 훨씬 나쁩니다.

```python
cal.coverage()
# {
#   "known_from": 2015, "known_to": 2035,
#   "caveats": ["설날·추석·석가탄신일은 음력이라 계산 불가 — 2015~2035 표를 사용합니다.", ...]
# }
```

## 5. 검증 방법

외부 라이브러리가 없으므로, **공개된 실제 휴장일**을 테스트에 직접 적어놓고
계산 결과와 대조합니다. "코드가 스스로를 확인"하는 게 아니라
**"바깥 사실과 대조"** 합니다.

가장 강한 교차검증 두 개:

```
2024년 NYSE 거래일 = 252일   ✅ 일치
2025년 NYSE 거래일 = 250일   ✅ 일치 (카터 전 대통령 장례로 1/9 휴장)
```

이 숫자는 공개된 사실이고, 규칙이 하나라도 틀리면 맞을 수 없습니다.

## 6. 백테스트 연동

```python
BacktestEngine(warmup=60, exchange="XNYS")
```

결과의 `leak_guard.calendar` 에 이렇게 나옵니다.

**실제 거래일 데이터일 때**
```json
{
  "checked": true, "aligned_to_sessions": true,
  "non_session_bars": 0, "missing_sessions": 0,
  "trustworthy": true,
  "reason": "모든 봉이 실제 거래일이고 빠진 거래일도 없습니다. T+1 봉 = 다음 거래일."
}
```

**합성 데이터일 때**
```json
{
  "checked": true, "aligned_to_sessions": false,
  "non_session_bars": 57,
  "trustworthy": false,
  "reason": "봉이 실제 거래일과 일치하지 않습니다. 'T+1 봉' 을 '다음 거래일' 로 해석하면 안 됩니다."
}
```

★ 합성 데이터는 주말에도 봉이 있습니다. **엔진이 그것을 알아채고 말해줍니다.**

## 7. 조기폐장

NYSE 는 아래 날에 13:00 ET 에 닫습니다. 날짜를 표시하지만
**시각 단위 거래는 다루지 않습니다** (일봉만 쓰기 때문).

- 추수감사절 다음날
- 성탄 전야 (평일일 때)
- 독립기념일 전날 (평일일 때)

---

## 8. 알려진 한계

| 한계 | 설명 |
|---|---|
| 미래의 1회성 특별 휴장 | 대통령 장례·재해 등은 표에 없으면 알 수 없습니다 |
| 한국 임시공휴일 | 새로 지정되면 `_KRX_EXTRA` 표를 갱신해야 합니다 |
| 반일 거래 시각 | 날짜만 표시하고 시각은 다루지 않습니다 |
| 타 거래소 | XNYS / XKRX 만 지원합니다 |

새 휴장일이 생기면 `packages/market_calendar/calendar.py` 의
`_NYSE_SPECIAL_CLOSURES` 또는 `_KRX_EXTRA` / `_KRX_LUNAR` 에 한 줄 추가하면 됩니다.
