# 학습 영속화 (Phase 5b)

> **"껐다 켜면 학습이 전부 사라진다"** — 이 시스템에서 가장 아팠던 제한을 없앴습니다.

---

## 1. 무엇이 달라졌나

이전에는 에이전트가 4시간을 공부해 모델 가중치를 고쳐놔도,
`stop.ps1` 을 누르는 순간 전부 사라졌습니다. 그러면 "매일 학습한다"는
설명이 사실상 거짓말이 됩니다.

이제 **SQLite 파일 하나**에 학습 결과가 남습니다.

```
C:\ai-research\data\airo.db
```

다시 켜면 이렇게 나옵니다.

```
[OK] 이전 실행에서 이어집니다 (에이전트 16명, 예측 925건, 3일차).
```

## 2. 왜 PostgreSQL 이 아니라 SQLite 인가

| | SQLite | PostgreSQL |
|---|---|---|
| 설치 | **불필요** (파이썬에 내장) | Docker + 드라이버 + 비밀번호 |
| 오늘 당장 동작 | ✅ | ❌ (Docker Desktop 필요) |
| 여러 대에서 공유 | ❌ | ✅ |
| 대용량 동시 쓰기 | 약함 | 강함 |

이 시스템은 **antking님 PC 한 대**에서 돕니다. 그 조건에서 SQLite 는
충분할 뿐 아니라 더 낫습니다. Docker 가 꺼져 있어도, 인터넷이 없어도 됩니다.

PostgreSQL 이 필요해지는 시점(여러 대에서 같은 데이터를 볼 때)을 위해
같은 인터페이스(`Store` 프로토콜)를 만들어 두었습니다. 그때는
`packages/persistence/store.py` 에 어댑터만 추가하면 됩니다.

> `open_store(backend="postgres")` 는 지금 **조용히 SQLite 로 내려가지 않고**
> 명확한 오류를 냅니다. 사용자가 무엇을 쓰고 있는지 알아야 하기 때문입니다.

## 3. 무엇을 저장하고 무엇을 저장하지 않나

### 저장합니다

| 항목 | 이유 |
|---|---|
| 모델 가중치 | **이게 곧 '배운 것'** 입니다 |
| 학습 통계 (정확도·캘리브레이션·표본 수) | Trust Score 의 근거 |
| 누적 유효 학습시간 | "오늘 4시간"이 재시작으로 리셋되면 안 됩니다 |
| 예측 저널 + 채점 결과 | 복기해야 실력이 늡니다 |
| 승인된 지식 | 검증을 통과한 사실 |
| **기각된 지식** | ★ 이력을 잃으면 어제 거른 루머를 오늘 다시 검증합니다 |
| 경과일·비용 장부 | 며칠째 일하고 있는지 |
| 시세 캔들 (`bars`) | 실데이터 |
| PIT 사실 (`facts`) | 4개 시간축과 함께 |

### 저장하지 않습니다

| 항목 | 이유 |
|---|---|
| **API 키·비밀번호** | ★ 절대 저장하지 않습니다 |
| 현재 위치·상태 | 재시작하면 새 하루가 시작됩니다 |
| 합성 시세 캐시 | 시드로 언제든 똑같이 다시 만듭니다 |
| 실행 중이던 작업 | 끊긴 작업을 되살리면 더 헷갈립니다 |

## 4. 언제 저장되나

| 시점 | 설명 |
|---|---|
| **200틱마다** | `AUTOSAVE_EVERY_TICKS` 로 조정 |
| **하루가 바뀔 때** | 여기서 잃으면 하루치가 통째로 날아갑니다 |
| **종료할 때** | `engine.close()` |
| **수동** | Settings 화면의 "지금 저장" 또는 `.\scripts\db.ps1 -Save` |

## 5. ★ 저장소 때문에 프로그램이 안 켜지는 일은 없습니다

이것이 이 계층의 첫 번째 설계 규칙입니다.

```
저장소를 못 엶       → 메모리 전용으로 계속 실행 + 화면에 경고
스냅샷 형식이 다름    → 호환되는 부분만 복구 + 나머지는 건너뜀
에이전트 하나가 깨짐  → 그 한 명만 건너뛰고 나머지는 복구
저장 실패            → 로그만 남기고 계속 실행
```

메모리가 **진실의 원본**이고, DB 는 그것을 다음 실행까지 옮기는 통로일 뿐입니다.

## 7. 명령

```powershell
.\scripts\db.ps1                  # 상태 보기 (읽기 전용)
.\scripts\db.ps1 -Save            # 지금 저장
.\scripts\db.ps1 -Backup          # data\backup\ 으로 복사
.\scripts\db.ps1 -ResetLearning   # ★ 합성 학습만 초기화 (시세는 남김)
```

### ★ `-ResetLearning` — 실데이터로 넘어갈 때

합성 캔들 생성기에는 **의도적인 사인파 사이클**이 들어 있습니다.
그 위에서 배운 모델은 "되돌림이 잘 먹는다"를 학습합니다. 실제 시장은 그렇지 않습니다.

실데이터로 넘어갈 때 그 가중치를 그대로 두면, 에이전트는
**없는 규칙을 이미 믿는 상태**로 시작합니다. 새로 배우기는 하지만 느리고,
초기 판단이 오염됩니다.

| 지웁니다 | 남깁니다 |
|---|---|
| 모델 가중치 | 실제 시세 (`bars`) |
| 학습시간 | PIT 사실 (`facts`) |
| 예측 저널 | `data\market\` 의 CSV |
| 승인·기각 지식 | 스키마 |

시세를 남기는 이유: **그건 배운 게 아니라 받아온 사실**이기 때문입니다.
다시 받을 필요가 없습니다.

안전장치:
- 백엔드가 켜져 있으면 **거부합니다** (메모리 상태가 곧바로 다시 저장되어 초기화가 무효가 됨)
- 지우기 전에 **항상 자동 백업**합니다 (`data\backup\airo-before-reset-*.db`)
- `y/N` 확인을 받습니다

**복원**: 백업 파일을 `data\airo.db` 로 되돌려 놓고 다시 실행하면 됩니다.

**전체 초기화**(venv·node_modules 까지): `.\reset-local.ps1` (확인 프롬프트 포함).
`db.ps1` 이 지울 수 있는 것은 **학습 기록뿐**이고, 그것도 백업 후에만 지웁니다.

## 8. 스키마

| 버전 | 테이블 | 내용 |
|---|---|---|
| 1 | `schema_meta`, `kv`, `events` | 기본 |
| 2 | `predictions` | 예측 저널 |
| 3 | `facts`, `bars` | PIT 사실, 시세 캔들 |

마이그레이션은 **앞으로만** 갑니다. 버전이 올라가면 필요한 것만 추가로
실행하고, 이미 적용된 것은 건너뜁니다.

### ★ `facts` 테이블의 PIT 규칙

정정 공시가 들어와도 **기존 행을 UPDATE 하지 않습니다.** 새 버전을 INSERT 합니다.

```sql
SELECT * FROM facts
WHERE key = ? AND published_time <= ?     -- ★ as_of 이후 공개분은 조회 불가
ORDER BY published_time, version
```

"미래를 보지 마세요"라고 부탁하는 방식이 아니라, **볼 수 있는 통로가 없습니다.**
