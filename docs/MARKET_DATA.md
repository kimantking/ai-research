## 4. 넣으면 자동으로 하는 검사

| 검사 | 무엇을 잡는가 | 실패하면 |
|---|---|---|
| **OHLC 모순** | `high < low`, 종가가 범위 밖 | ❌ 적재 거부 |
| **중복 날짜** | 같은 날이 두 번 | ❌ 적재 거부 |
| **시간 역순** | 정렬이 깨진 파일 | ❌ 적재 거부 |
| **0 이하 가격** | 파싱 오류·빈 값 | ❌ 적재 거부 |
| **거래일 정렬** | 주말·휴장일에 봉이 있음 | ⚠️ 경고 |
| **결손** | 거래일인데 데이터 없음 | ⚠️ 경고 |
| **분할 의심** | 하루 ±50% 이상 변동 | ⚠️ 경고 |

**거부는 좋은 일입니다.** 조용히 통과한 쓰레기 데이터는 그럴듯한 백테스트
결과를 만들어 내고, 그게 훨씬 위험합니다.

## 5. ★ MOCK / MIXED / REAL

화면 왼쪽 위 배지는 **세 가지 상태**를 구분합니다.

| 배지 | 뜻 |
|---|---|
| `MOCK DATA` (노랑) | 전부 합성 데이터 |
| `MIXED — 실데이터 N종목` (주황) | **일부만** 실제 |
| `REAL DATA` (초록) | 사용 중인 종목이 전부 실제 |

> **왜 MIXED 를 따로 두었나**
> 개발 중에 "실데이터 2종목을 넣었으니 이제 LIVE" 로 표시되는 버그를
> 만들었다가 잡았습니다. 나머지 7종목이 여전히 합성인데 화면은
> 초록불이었습니다. **그건 거짓말입니다.** 그래서 상태를 셋으로 나눴습니다.

---

## 6. ★ 조정주가를 기본으로 쓰지 않는 이유

조정주가(adjusted close)는 분할·배당이 발생하면 **과거 값이 소급해서 바뀝니다.**

```
2024-06-01 에 본 애플 2020년 종가   →  X
2024-07-01 에 본 애플 2020년 종가   →  Y   (그 사이 배당이 있었다면 X ≠ Y)
```

백테스트에서 이 값을 그대로 쓰면, 2020년 시점의 전략이
**2024년에야 알 수 있는 정보**를 쓰게 됩니다. 수익률은 좋아지고,
실전에서는 재현되지 않습니다.

그래서 이 시스템은 **원주가(raw)** 를 기본으로 쓰고,
분할로 보이는 급변 구간을 경고로 표시합니다.

## 7. Point-in-Time 처리

일봉 하나가 저장될 때 네 개의 시간이 붙습니다.

```
event_time      2024-01-02 00:00 UTC   ← 그 거래일
published_time  2024-01-02 21:00 UTC   ← ★ 장 마감 후. 조회 기준
received_time   우리가 받은 시각
effective_time  = published_time
```

**핵심**: 종가는 장이 끝나야 확정됩니다.
`published_time` 을 봉 날짜 00:00 로 두면 **그날 아침에 그날 종가를 아는 것**이
되어 버립니다. 그래서 거래소별 마감 시각을 더합니다.

| 거래소 | 마감 (UTC 기준 오프셋) |
|---|---|
| XNYS | +21시간 (미 동부 16:00) |
| XKRX | +6시간 30분 (한국 15:30) |
| 그 외 | +23시간 (가장 보수적) |

테스트 `test_pit_store_hides_the_close_before_the_close` 가 이것을 강제합니다.

## 8-b. ★ 합성 → 실데이터 전환 절차 (권장)

에이전트들이 이미 합성 데이터로 학습해 왔다면, 넘어가기 전에 한 번 정리하는 것이 좋습니다.

```powershell
.\stop.bat                          # 1) 백엔드를 먼저 끕니다
.\scripts\db.ps1 -ResetLearning     # 2) 합성 학습만 지웁니다 (자동 백업됨)
.\start.bat                         # 3) 다시 실행
.\fetch-data.bat                    # 4) 실제 시세 적재
```

**왜**: 합성 생성기에는 의도적인 사이클이 있어서, 그 위에서 배운 가중치는
실제 시장에 없는 규칙을 담고 있습니다. 자세한 내용은 `docs/PERSISTENCE.md`.

건너뛰어도 동작은 합니다. 다만 초기 판단이 합성 데이터 쪽으로 기울어 있습니다.
