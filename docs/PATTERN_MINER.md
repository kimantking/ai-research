# PATTERN MINER

> 이 파일에서 제일 중요한 것은 **패턴을 찾는 코드가 아니라
> 찾은 패턴을 믿지 않는 코드**입니다.

구현: `packages/pattern_miner/miner.py`
테스트: `tests/test_backtest_and_patterns.py`

---

## 1. 무엇을 하는가

사람이 알려준 패턴(헤드앤숄더 등)만 연구하지 않습니다.
지표 조건을 조합해서 **반복적으로 발생하는 것**을 탐색합니다.

현재 조건 17종 × (1개 또는 2개 조합) = **후보 153개**

```
RSI<30 / RSI>70 / RSI 40~60
종가>SMA20 / 종가<SMA20 / SMA20>SMA50 / SMA20<SMA50
ADX>25 / ADX<20
RVOL>1.5 / RVOL<0.8
ATR%>3 / ATR%<1.5
ROC10>5 / ROC10<-5
52주고점근접 / 52주저점근접
```

## 2. 과적합 방지 — 시간 분할

```
|<──── TRAIN 50% ────>|<── VALIDATION 25% ──>|<── TEST(OOS) 25% ──>|
        여기서만 발견        1차 확인            마지막에 한 번만
```

### 왜 무작위 분할이 아닌가

시계열을 무작위로 섞으면 **미래가 과거에 섞여 들어갑니다.**
2026년 데이터로 학습하고 2025년 데이터로 검증하면 그건 검증이 아닙니다.

`TimeSplit.overlaps()` 가 구간 겹침을 검사하고, 겹치면 실행 자체를 중단합니다.

---

## 3. 승격 기준 — 대부분을 기각합니다

| 판정 | 조건 |
|---|---|
| `INSUFFICIENT_SAMPLE` | 학습 구간 표본 < 40건 |
| `NO_EDGE` | 학습 승률이 50%에서 2%p 이내 (동전던지기) |
| `UNVERIFIED` | 홀드아웃 표본 < 25건 |
| `FAILED_VALIDATION` | 학습에선 좋았는데 검증에서 무너짐 → **과적합** |
| `FAILED_OUT_OF_SAMPLE` | OOS 에서 방향이 뒤집힘 |
| `REDUNDANT` | 조건을 더 붙였는데 표본이 그대로 → 같은 패턴 중복 계상 |
| `WEAK` | 세 구간 방향은 일치하나 우위가 약함 |
| **`STRONG`** | **세 구간 모두 방향 일치 + 표본 충족** |

### 실측 분포 (합성 데이터)

```
후보 153개 → STRONG 8, WEAK 2, FAILED_OUT_OF_SAMPLE 34,
             FAILED_VALIDATION 30, INSUFFICIENT_SAMPLE 51, NO_EDGE 17, UNVERIFIED 11
```

**후보의 5%만 살아남습니다. 이게 정상입니다.**
후보 대부분을 STRONG 으로 승격시키는 마이너는 고장난 것입니다.
`test_most_candidates_are_rejected` 가 이걸 강제합니다.

---

## 4. REDUNDANT 판정 — 같은 패턴 중복 계상 방지

```
RSI>70                     train 103건, 승률 74.76%
RSI>70 + 종가>SMA20        train 103건, 승률 74.76%   ← 표본이 똑같음
```

이 데이터에서 `RSI>70` 이면 자동으로 `종가>SMA20` 입니다.
두 번째 조건은 아무 일도 하지 않았습니다.

이걸 따로 세면 "STRONG 패턴 8개 발견"이 부풀려집니다. 실제로는 같은 패턴입니다.
그래서 `REDUNDANT` 로 내려 제외합니다.

## 5. 기록하는 통계

```
pattern_id, conditions, direction(UP/DOWN), horizon, sector, market_regime
구간별:  sample_size, win_rate, avg_return, median_return, worst_return,
        avg_MAE(최대 역행), avg_MFE(최대 순행)
```

**worst_return 을 반드시 함께 봅니다.** 승률 70%인데 지는 30%에서 −40% 나면
그 패턴은 쓸 수 없습니다.

## 6. 결과에 항상 붙는 경고

```
⚠ 현재 데이터는 합성(MOCK) 시계열입니다. 생성기에 의도적으로 완만한 사이클이
  들어 있어 모멘텀 조건이 잘 맞습니다. 여기서 나온 높은 승률은 실제 시장의 우위를
  전혀 의미하지 않습니다.

⚠ 표본이 겹칩니다: 5일 수익률 창이 서로 중첩되므로 표본들이 서로 독립이 아닙니다.
  승률의 통계적 유의성은 표본 수가 시사하는 것보다 낮습니다.

⚠ 여러 종목에 같은 조건을 적용해 합산했습니다. 종목 간 상관이 높으면
  실제 독립 표본 수는 더 적습니다.

⚠ STRONG 은 '세 구간에서 방향이 일치했다'는 뜻이지 '앞으로도 통한다'는 뜻이 아닙니다.
```

이 경고를 UI 상단에 크게 띄웁니다. 숨기지 않습니다.

## 7. 아직 안 한 것

- **Walk-forward 검증** — 순차 전진 재검증 (Phase 20)
- **Market regime 별 분리** — 상승장/하락장/횡보장에서 다르게 동작하는지
- **다중검정 보정** — 153개를 테스트하면 5%는 우연히 유의하게 나옵니다.
  Bonferroni 또는 FDR 보정이 필요합니다. 현재는 **미적용**이며, 이것이
  가장 큰 통계적 약점입니다.

정직하게 적어둡니다. 지금 결과는 "탐색적"이며 확증적이지 않습니다.
